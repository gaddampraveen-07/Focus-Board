# Screenshots Directory

This directory is prepared for capturing and submitting dashboard preview screenshots for the MobileFirst FocusBoard assignment evaluation:

1. **desktop-1440.png**: Desktop dashboard (1440 × 1000) showing sidebar, header, dynamic statistics, Focus Notes carousel, filters, and task list.
2. **mobile-390.png**: Mobile dashboard (390 × 1128) showing collapsible mobile navigation, stacked statistics, and touch-friendly task cards.
3. **tablet-768.png**: Tablet responsive layout (768px) with 2-column statistics grid and refined filter tabs.
4. **create-task-modal.png**: Create & Edit task modal with validation states.
5. **delete-confirmation.png**: Two-step deletion confirmation dialog.
